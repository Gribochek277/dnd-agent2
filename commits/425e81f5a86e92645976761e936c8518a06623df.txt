feat(llm): repeat guard N=3 for identical tool calls in one pass (#117)
Spec §6 (gap G4): the production agent harness bounded a pass by the
number of tool calls (8) but never detected repetition. Add the streak
breaker alongside that bound:

- N = 3 consecutive identical completed calls (tool name + normalized
  arguments) in one pass cut the pass; key order in the arguments is
  irrelevant (ordinal sort), the reject flag is not part of the identity.
- Every completed call counts (rejected and successful alike); any other
  call or a pass boundary resets the streak.
- The trip goes through the same path as the per-pass bound: the pass
  ends, the turn gets the existing ToolLoopFallbackNote, and the calls
  that already ran keep their effect (no rollback). Diagnostics record a
  distinct RepeatedToolCallStreak action / ToolCallStreak fallback reason.
- The threshold is injectable via the constructor (default 3).

The existing tool-storm test now varies its arguments: a storm of
different calls is the per-pass bound's job, identical calls are the
streak guard's.
