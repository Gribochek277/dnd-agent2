feat(encounters): triggered check generates and plays out an encounter (issue #30)
The periodic exploration check (every 4th turn, danger level 6) printed
'⚠ Something stirs…' and dead-ended. A successful check now generates a
real encounter via the NPC generator (GenerateEncounterAsync, scaled to the
party's average level) and hands the stat blocks to the DM for narration —
the same path as TriggerRandomEncounterTool: the DM can DeclareEncounter/
StartCombat when the fight breaks out, or resolve it socially/environmentally.
A failed check still prints nothing; generation failure falls back to the DM
inventing the encounter instead of crashing the loop.

The encounter prompt is recorded in chat history as a 'system' turn (new
optional sender on IDmAgent.SendAsync) so it never pollutes player-language
detection or looks like a player claim.

Tests: InputLoopEncounterTests (hit → DM narrates generated encounter;
miss → nothing printed; generation null / throwing → DM still narrates) and
RandomEncounterServiceTests (danger roll gating, stat-block generation via
the NPC generator).
