feat(llm): server owns sampling by default — per-role temperature moved to config
The agent no longer overrides the sampling temperature on every call:
- ILlmClient.SendPromptStreamingAsync / IAgentStreamSource.StreamAsync now
  take float? temperature = null; null omits the field from the request,
  so the server's own sampling settings apply (llama.cpp --temp, top-p/k).
- Per-role overrides stay available in config:
  LLM:DmTemperature / EnemyDecisionTemperature / EnemyNarrationTemperature /
  NpcTemperature / MemoryTemperature (all null by default; keys documented
  in appsettings.json).
- Removed hardcoded constants (DM 0.8, enemy decision 0.2 / narration 0.8,
  stat block 0.2, memory 0.3) — DmAgent, EnemyAIService, NpcGeneratorService,
  MemoryService now read IOptions<LlmConfig> (optional ctor param).
- Debug trace prints temperature=server-default when unset.
- Tests: fakes updated to the nullable signature; EnemyAIService fake now
  discriminates decision/narration by prompt content, not temperature.

Verified live: [llm] attempt 1/4 ... temperature=server-default.
