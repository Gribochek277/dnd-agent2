feat(xp): milestone/quest XP rewards via GrantMilestoneXp tool + DM prompt rules (#19)
Issue #19: leveling was unreachable in a session (all fights 50 XP, level 2
needs 300 XP). Add a milestone/quest XP path on top of the existing XpTracker
mechanics:

- GrantMilestoneXp DM tool: awards the same XP to every party member after a
  completed story goal, triggers TryLevelUp (HP/slots/proficiency per 5e),
  rejects non-positive amounts, empty reasons, and grants during combat.
- Registered in DmAgentToolProvider; result message carries XP + level-ups.
- System prompt: milestone-reward rules for the DM (minor 25-50, major
  100-150, main quest 200-250 XP) so '2 fights + quest' reaches level 2,
  plus an adjudication line that XP narration requires the tool.
- ToolEventFormatter renders '🏆 <goal> / ✨ XP +N / ⬆️ <level-up>' lines;
  MechanicalOutcomeClaimDetector authorizes XP narration after an accepted
  GrantMilestoneXp; per-turn reminder lists the tool.
- Tests: tool (grant, rejections, combat guard, two-fights+quest → L2
  acceptance scenario), formatter, detector, prompt rules. Build clean,
  full suite green (522 tests, +9).
