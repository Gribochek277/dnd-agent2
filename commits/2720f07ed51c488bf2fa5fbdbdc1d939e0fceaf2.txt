- ChatClientAgentStreamSource: a pass with no narratable content is re-requested
  with a simplified prompt while the bounded pass budget remains (max 2 retries);
  when the budget is exhausted — or a tool already ran that pass (re-running
  could double-apply a state change) — yield the neutral fallback narrative
  ("Ты оглядываешься — вокруг тихо…") instead of yielding nothing.

  stalled LLM never hangs the game loop; a stream that ends with no tokens
  (empty answer, timeout before any token) streams the fallback narrative and
  records it in chat history. Caller cancellation still propagates — it is
  never misread as a turn timeout.

  forwarded before any narration, as before.

  → fallback within bound, tools-ran → no retry (fallback), stalled stream →
  timeout fallback, empty stream → fallback, caller cancel propagates, and
