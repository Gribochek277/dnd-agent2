feat(levelup): точные фичи/спеллы класса из БД правил на level-up (#67)
Проблема: DM рассказывал про новые класс-фичи «по памяти» — источник
несуществующих/неверных фич. Теперь систему направляет seeded class-feature DB.

- IClassFeatureCatalog/SrdClassFeatureCatalog (Dnd.DM): для класса и нового
  уровня отдаёт точный список фич из SRD-категории features (match по
  class + level_req) и спеллов только что открывшегося уровня заклинаний
  (через существующую ISpellSlotCalculator-прогрессию).
- Оба пути левел-апа (GrantXpTransitionAction, GrantMilestoneXpTool) строят
  структурный LevelUpGrant на IGameStateContext.LevelUpGrants.
- PromptBuilder рендерит <new_class_features>/<new_spells> внутри <level_up>
  с явным требованием пройтись по каждому пункту и не выдумывать лишнего;
  класс вне датасета → ClassFeaturesKnown=false + честная пометка no data,
  ход не падает.
- Тесты: известный класс/уровень (Barbarian 2 → Reckless Attack, Danger Sense),
  неизвестный класс (пусто + пометка), попадание в контекст левел-апа.
  dotnet test Dnd.slnx зелёный (1565 тестов).
