prototype: live trial runner + production config for trials
- Dnd.Evals.Run: manual live-run entry point (scenario id -> full trial,
  verdict + transcript), the no-CI manual-run shape from the map.
- WorldSeeder loads Dnd.CLI/appsettings.json so a trial runs the exact
  production LLM configuration (reasoning budget, max output, compaction);
  only endpoint/model identity is overridden.

Field finding from the first live trial: default LlmConfig (MaxOutputTokens
1024, thinking medium) starves a thinking model — the stream no-data
watchdog fires and the turn falls back to empty narration. Production
appsettings (8192 / low / 4096) avoids it.
