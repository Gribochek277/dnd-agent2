Gate system combat entry on extracted attack target (issue #36)
AttackIntentRegex alone (атакую|бью|удар*) triggered the issue #27 system
combat start for peaceful actions that merely contain a combat word
("Я бью в дверь, чтобы открыть её", "Ударю кулаком по столу"),
force-starting combat with the fallback "Враг" after the model resolved
the action peacefully.

The force-start now also requires an extracted attack target: AttackTargetRegex
rejects prepositional strikes (в/по right after the verb are no longer treated
as naming a target), so only direct-object attacks ("Атакую гоблина мечом")
still guarantee the combat transition. Real attacks keep starting combat
(issue #27 regression covered by tests).
