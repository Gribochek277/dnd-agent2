test: full-turn rig — player input → agent → tools → narration (#116)
Gap G3 from the #105 testing audit (epic T #113, MVP step 3): the component
layer knew only sub-decisions of the model; there was no test that played a
whole DM turn. ChatClientAgentStreamSourceTests drives the streaming loop on
fakes, but never the agent + tools + state path.

Add a reusable FullTurnRig (Dnd.CLI.Tests/Support) that runs ONE real turn
through the real IDmAgent — LlmClient, ChatClientAgentStreamSource, a real
ChatClientAgent and the real DmAgentToolProvider tools — against a scripted
model and scripted dice. The real classifier/adjudicator stay in the graph and
answer from a fake verdict, so enforcement behaves as in production. Only three
seams are scripted: the tool-calling agent model, the dice, and the
non-streaming sub-model calls. No live model, no network.

Shared assets (TestSupport/, linked into Dnd.CLI.Tests):
- ScriptedChatClient  — streaming model replaying tool calls then narration
- ScriptedDiceEngine  — dice queues keyed by expression (spec §4)
- FakeOpenAiChatClientFactory — sub-model calls served by the shared FakeChatClient
- NullTurnDiagnosticsLogger — keeps a turn test from writing JSONL files

Tests, one per aspect with a component form:
- FullTurnConversationTests — conversational turn: narration, no tool call
- FullTurnCombatTests — attack in Exploration: StartCombat + AttackRoll change state
- FullTurnCheckTests — requested check/save: AssignDC + TriggerSave, typed result
  (covers ability check and saving throw)

dotnet test Dnd.slnx green (1262 tests).
