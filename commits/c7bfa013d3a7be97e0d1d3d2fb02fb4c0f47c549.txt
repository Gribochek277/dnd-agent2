fix(#41): drop stale RestRequested when no longer in an eligible state
A rest declared in fiction is a one-shot intent. If the game leaves the
eligible states (Exploration/Social) before the transition is observed —
e.g. combat breaks out during the DM turn — the leftover RestRequested
now is cleared instead of deferred, so it can never fire an unexpected
Rest on a later turn that returns to Exploration/Social.

Adds a regression test that forces Combat before the attack turn and
asserts the stale request is dropped (fails without this change).
