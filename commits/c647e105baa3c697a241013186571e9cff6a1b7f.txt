fix(narration): dedupe/typo/monolingual sanitizer + enemy decision render order (Gitea #17)
NarrationSanitizer now polishes the surviving narration on top of the existing
line filtering:
- deduplication of repeated sentences/paragraphs (exact, normalized, and
  near-exact via containment/Levenshtein), keeping at least one copy;
- typo dictionary from playtest 14.08.2026 (варара→варвара, велича→велика,
  озонов→озона, делашь→делаешь, Твоя факел→Твой факел, Грибной чудовище→
  Грибное чудовище + same-class agreement rules), word-boundary aware and
  case-preserving;
- monolinguality: EN lines are dropped from predominantly-Cyrillic blocks.

Enemy turn render order: IEnemyAIService gains an onDecision callback fired
as soon as the action is known, so InputLoop renders «decides: Attack» before
the dice/damage events and the narration (решение → событие → нарратив).
Enemy narration is now routed through the sanitizer too (collected, sanitized,
then emitted), matching the DM agent path.

Tests: +11 sanitizer unit tests, +2 enemy-AI tests (decision order, sanitized
narration), +1 CLI integration test (Start → decides → event → narration →
End). dotnet build 0 errors (only known NU1903/CS8632), all 527 tests green.
