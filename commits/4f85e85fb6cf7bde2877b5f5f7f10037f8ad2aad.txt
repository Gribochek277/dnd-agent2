Compact history with structured LLM summary instead of hard trim (issue #29)
When the full prompt exceeds the context budget (context minus the response
reserve), the oldest turns are replaced by a single LLM-generated structured
summary (Goal / Progress / Key Decisions / Critical Context) while the freshest
Compaction:KeepRecentTokens tokens stay verbatim. The summary is written in the
player's language, preserves premise/NPCs/decisions/items, and is merged with
the previous summary on repeated compactions (pi-style iterative compaction).
The summary entry lives in the chat history so /save and /load keep working;
the summarization pass is a plain completion with thinking disabled and never
triggers game tools. PromptBuilder keeps a defensive trim (single enormous
turn, LLM unavailable) that never evicts the summary entry.
